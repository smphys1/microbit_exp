# 탐구노트 ver3: 파일로 제출하고 교사가 채점하기

## 주소와 기존 버전

- ver1: https://microbit-inquiry-lab-dh.workspace-489790.chatgpt.site/
- ver2: https://smphys1.github.io/microbit_exp/
- ver3 학생: https://smphys1.github.io/microbit_exp/ver3/
- ver3 교사: https://smphys1.github.io/microbit_exp/ver3/teacher/

ver3는 별도 HTML·React 진입점을 사용합니다. ver2 화면과 동작은 유지하며 초안·학생 접속 정보·평가 저장소도 분리합니다. ver1 배포에는 변경을 가하지 않습니다. GitHub Actions 배포가 완료된 뒤 새 주소를 사용할 수 있습니다.

## 학생 사용 순서

1. ver3에서 학번과 이름을 입력합니다. 계정과 비밀번호는 없습니다.
2. 주제·실험 설계·보고서를 작성하고 변인 통제·반복·단위 점검을 완료합니다.
3. 원본 CSV와 그래프가 포함된 XLSX를 선택합니다. CSV는 최대 8개, XLSX 1개, 선택 그래프 이미지 1개입니다. 파일당 10 MB, 합계 20 MB 이내이며 그래프는 5 MB 이내입니다.
4. 마지막 단계의 **제출 파일 저장(JSON)**을 눌러 보고서와 실제 첨부 파일 바이트를 하나의 파일로 저장합니다.
5. 선생님이 안내한 클래스룸·학교 제출함 등의 경로로 그 JSON 파일을 전달합니다. 이 앱이 선생님께 자동 전송하지는 않습니다.

**작성 백업**은 텍스트·점검 내용을 옮기는 용도이고 첨부를 포함하지 않습니다. 교사 화면에는 반드시 **제출 파일 저장(JSON)**으로 만든 파일을 가져와야 합니다. ver2 작성 백업을 ver3로 불러올 수 있지만 필수 파일은 다시 선택해야 합니다. 새로고침하면 첨부 파일도 다시 선택해야 합니다.

## 교사 채점

1. 교사 주소를 열어 학생 제출 JSON을 여러 개 선택합니다. 잘못된 파일은 오류를 표시하고 기존 자료를 덮어쓰지 않습니다.
2. 학번·이름·학급·주제로 검색하고 학생을 선택합니다.
3. CSV 앞 25행을 미리 보거나 원본을 다운로드합니다. XLSX는 내려받아 시트와 그래프를 직접 확인합니다. 파일이 있다는 이유만으로 자동 채점하지 않습니다.
4. 주제 5항목(각 2/1/0점), 파일 10항목(각 1/0점), 보고서 5영역(4+6+8+8+4점)을 채점하고 피드백을 입력합니다. 총 50점입니다.
5. **채점 결과 저장**을 누릅니다. 필수 점수 선택이 끝나지 않으면 저장할 수 없습니다. 다른 탭에서 해당 제출이나 채점이 바뀐 경우에는 저장을 거부하고 다시 확인하도록 안내합니다.
6. **채점 결과 CSV**로 명단·영역별 점수·총점·피드백을 내보냅니다.
7. **학생용 평가 파일 저장**으로 선택한 학생의 결과 JSON을 내려받아 학생에게 직접 전달합니다. 웹에 자동 공개되지 않습니다.

같은 제출 파일을 다시 가져오면 기존 채점을 유지합니다. 같은 학번·이름의 다른 내용 파일을 가져오면 확인 후 기존 자료를 교체하고 채점을 초기화합니다. 교체하기 전에 제출 원본과 채점 백업을 따로 보관하세요. 이 앱은 학생별 최신 제출 하나를 보관하며 제출 이력 전체를 관리하지 않습니다.

## 채점 저장과 백업

교사 자료는 현재 기기·현재 브라우저·현재 사이트의 IndexedDB에 저장됩니다. 서버·GitHub·다른 사용자에게 업로드되지 않습니다. 공개 교사 페이지에 공유 학생 명단은 없으므로 별도 교사 비밀번호도 없습니다. 같은 기기와 브라우저를 쓰는 사람은 저장된 자료를 볼 수 있습니다. 개인 기기를 사용하고 공용 기기에 개인정보를 남기지 마세요.

**채점 백업 저장** 파일에는 점수·피드백과 제출 식별자가 들어 있으며 학생 첨부 원본은 포함하지 않습니다. 사이트 데이터 삭제, 브라우저 변경, 기기 교체 전에 학생 제출 원본과 채점 백업을 모두 보관합니다.

다른 기기에서 복원할 때는 학생 제출 JSON을 먼저 가져온 뒤 **채점 백업 복원**을 사용합니다. 동일한 제출 식별자의 점수만 복원하며, 내용이 달라진 재제출에는 이전 점수를 적용하지 않습니다. 복원 시 기존 채점을 바꾸는지 확인합니다.

## 학생이 평가 확인하기

학생은 교사가 전달한 평가 JSON을 ver3 마지막 단계의 **교사가 보내 준 평가 결과 확인**에서 가져옵니다. 현재 학생과 다른 학번·이름의 결과는 거부합니다. 평가 대상 제출과 현재 수정 중인 내용은 다를 수 있으므로 제출 식별자를 함께 표시합니다.

학번·이름은 본인 확인 수단이 아니며 제출·평가 파일의 진위를 인증하지 않습니다. 파일 내용의 해시는 손상·불일치 탐지용입니다. 교사가 보관한 원본 채점이 기준이며, 학생에게 전달한 파일은 별도로 편집될 수 있습니다.

## 개발과 배포

```sh
pnpm dev
pnpm exec tsc --noEmit
pnpm test
pnpm build:pages
pnpm preview:pages
```

Pages 빌드는 ver2 루트, ver3 학생, ver3 교사의 HTML 세 개와 공유 자산을 생성합니다. 하위 경로에서 상대 자산 URL을 사용합니다. 서버·Google OAuth·Cloudflare 계정이나 비밀 값 없이 실행할 수 있습니다. `main`에 푸시하면 기존 GitHub Pages 워크플로가 세 화면을 함께 배포합니다.
